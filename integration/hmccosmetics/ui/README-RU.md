# The Axiom — русификация HMCCosmetics (тестовый интерфейс)

Эта папка — **только конфигурация** для встроенных меню HMCCosmetics 2.9.3. Рабочий AxiomWardrobe (скины/ауры/сайт) не изменён.

## Что исправлено
- `00` в заголовке исходного меню — это специальные символы шрифта, который отсутствует в ресурспаке The Axiom. Здесь вместо них — обычные русские названия.
- Навигационные кнопки теперь используют ванильные предметы без CustomModelData, поэтому сами кнопки не зависят от дополнительных текстур.
- Lore `Enabled/Allowed` переведены как `Надето/Доступно`, плейсхолдеры оставлены.
- В `defaultcosmetics.yml` переведены названия демонстрационных предметов, но **сохранены ID, слоты, права и модельные данные**.

## Перед тестом
1. На тестовом сервере остановить Paper и сделать копии:
   - `plugins/HMCCosmetics/menus/`
   - `plugins/HMCCosmetics/cosmetics/`
2. Скопировать четыре `menus/*.yml` в `plugins/HMCCosmetics/menus/`, сохранив их имена.
3. При желании перевести названия предметов — скопировать `cosmetics/defaultcosmetics.yml` в `plugins/HMCCosmetics/cosmetics/`; существующий файл предварительно сохранить.
4. Запустить Paper и открыть меню украшений через The Axiom; проверь заголовок, названия и переходы между категориями.
5. Если что-то не открылось, восстановить сохранённые копии; не менять AxiomWardrobe/Bridge/MySQL.

## Ограничение
Это не набор готовых 3D-моделей. Оригинальные `defaultcosmetics.yml` показывают **демонстрационные** косметические ID с `model-data`, но сами лицензированные модели должны поставляться отдельно и корректно объединяться ResourcePackManager. Без соответствующих assets предметы могут быть дефолтными, розово-чёрными или невидимыми. Не считаем функциональность 3D-косметики подтверждённой по одному экрану инвентаря.

Тестируем отдельно: смену статуса экипировки, реальный внешний вид при ходьбе и приседании, наблюдение вторым клиентом, уборку моделей при выходе, интеграцию с AxiomWardrobe.

Основано на примерах `HibiscusMC/HMCCosmetics` (ветка `remapped`, commit `92d9193f05f08d083c06be1f2597fc4016940b80`), GPLv3: https://github.com/HibiscusMC/HMCCosmetics/blob/remapped/license.md.
