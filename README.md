# The Axiom Wardrobe

Development repository for The Axiom cosmetics and skin infrastructure.

## Current branch content

`AxiomRigProbe` 0.9.6 is an isolated **admin-only** Paper 1.21.11 diagnostics plugin for wings attachment. This repository does not contain the production AxiomWardrobe server configuration, website credentials, MySQL credentials, or AxiomBridge secrets.

**Not production-ready.** The GitHub Actions workflow must compile against the real Paper API before any JAR can be tested. After a successful CI build, install only on a test server and inspect the result in a real Minecraft client. Keep the working 0.8.0 plugin unchanged.
